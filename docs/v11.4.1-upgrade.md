# v11.4.1 Live Photo 检查范围说明

此修订版明确区分全库检查和修复后的局部复查。此前“修复实况异常：检查 9 组”只代表本轮修复涉及内容的复查结果；左侧 Live Photo 统计含实况的动态数，两者不能直接比较。现在历史与新报告均标明范围，计数说明仍收在 `?` 中。
