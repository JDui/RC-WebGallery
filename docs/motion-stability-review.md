# 动效稳定性排查与修复

日期：2026-11-20。排查基线：`d648d03`。

本轮检查覆盖项目自有的前端动画入口、媒体交接、滚动和布局测量，以及关闭、重开、迟到回调、动画 API 失败和减少动画模式。下表记录能够从代码路径及回归用例确认的缺陷。优先级表示影响范围和操作阻塞程度，不代表测得的掉帧比例。

## 已处理的问题

| 区域 | 触发条件与根因 | 修复方式 |
| --- | --- | --- |
| 弹层首次入场 | Alpine 的 `x-show` 在动画帧显示节点，`$nextTick` 可能提前测到零尺寸，直接跳过来源动画 | 保留待显示状态，等待显示帧后测量并启动动画；关闭或重开会使旧帧回调失效 |
| 详情与任务弹层 | 入场过程中异步内容增高，百分比缩放中心随高度变化，使整个窗口跳动 | 对顶部对齐的弹层固定像素缩放中心；中断时保留当前中心，退场按更新后的尺寸计算返回目标 |
| 动画异常取消 | 外部取消 WAAPI 后，关闭流程可能一直等不到有效完成结果 | 区分显式中断和播放器异常取消；异常完成仍释放关闭状态及滚动锁 |
| 辅助弹层来源 | 部分浏览器点击按钮不会改变 `activeElement`，动画可能从上一个聚焦按钮开始 | 原帖、任务、垃圾桶和小红书入口显式传入实际事件目标；程序打开时没有来源就淡入 |
| Live Photo 查看器关闭 | 退场开始前重置播放时间、清掉视频帧并显示静态图 | 暂停但保留正在显示的帧，退出完成再释放；关闭后的排队播放请求被拒绝 |
| 视频流转场中关闭 | 取消子层滑动并立即删除旧播放器，使新视频先跳回中心 | 关闭期间保留两个播放器及其滑动状态，暂停播放并废弃迟到请求，父层退场结束后清理 |
| 查看器交接中关闭 | 图片交接尚未结束就隐藏邻图、取消当前帧渐变，导致退出前跳回旧图；慢速重开时旧清理可能覆盖新导航 | 保留交接画面直到父层退出，阻止迟到交接提交；释放旧画面时保留更新请求的序列、索引和来源 |
| 悬停预览退出 | 淡出前清空源和解码器，透明度过渡中出现首帧或空白 | 保留暂停帧到淡出完成；使用事件与超时兜底，旧清理回调不能影响新播放 |
| 渐进图片替换 | 旧 CSS opacity transition 与 WAAPI 同时控制图片；异常取消或隐藏页面时的 decode 交接缺少收尾 | 单一路径控制透明度；异常取消可继续后续更新；页面隐藏时保留最近已提交的画面 |
| 查看器回弹与翻页衔接 | 回弹未结束就启动已准备好的翻页，动画从零位移重新开始 | 读取当前渲染位移并接续；交接时取消子元素重复的 transform transition；部分 API 失败仍完成收尾 |
| 卡片重排 | 每张卡片交替读写布局，重叠 RAF/计时器可能清除新动画，也会覆盖 hover transform | 统一先读后写，以独立 translate 叠加原有 transform；逐元素记录动画归属，旧清理不影响新效果 |
| 审核列表移除 | 重排动画异常可能让移除 Promise 无法结束 | 复用有异常收尾的卡片重排逻辑；数据提交、移除状态与动画成功解耦 |
| 图库虚拟窗口 | 先测旧布局，且 spacer 绑定更新前就补偿锚点；旧请求、弹层或用户继续滚动时仍可能强制修正位置 | 先完成瀑布流布局，再测高度；等待第二次绑定刷新后补偿；校验请求、窗口代次、列表身份和滚动位置 |
| 窄屏瀑布流 | 逐张读取 offset 尺寸后立即写跨度；重复观察回调也不断写入相同值 | 批量测量后统一写入，只更新变化的跨度；忽略隐藏、已移除或切换到宽屏后的迟到回调 |
| 设置分组 | 快速切组时未持有上一段淡入，下一次淡出固定从 opacity 1 开始 | 持有淡入与淡出，取消前采样透明度；同组撤回平滑恢复；异常情况下仍提交当前选择 |
| 页面标题与玻璃高光 | 实际页面在 `.view-stack` 中却未被发现；错峰标题缺少等待帧；每个 pointermove 都读布局 | 修正页面定位，保留中断状态和等待帧；高光每帧合并读取，避免与 Alpine 的整页透明度争用 |
| 帮助提示 | 对整页样式写入的观察触发多余测量；滚动长提示内容会把提示本身关闭 | 仅在提示打开时观察来源及祖先；提示内部滚动保留，页面滚动仍关闭 |
| 响应式与合成状态 | 弹层锁住旧屏宽；桌面侧栏独立宽度过渡与已改变的内容布局错位；弹层长期保留 will-change | 锁定宽度改为随视口变化的相对值；桌面几何同步更新；只在实际动效期间启用合成提示 |

## 已检查且保留的逻辑

- 视频加载占位和可播放视频共享固定播放器区域，桌面和窄屏均预留高度；没有为此追加另一套高度动画。
- 低性能模式已抑制主要背景模糊；媒体卡片没有额外的背景模糊层。未整体移除已有玻璃效果。
- 系统减少动画偏好继续生效；新卡片重排在减少动画、低性能或被弹层覆盖时直接提交布局。
- 主层级缩放作用于外壳，视频滑动和图片交接作用于内部节点，避免同一个元素争用 transform。
- 图片和视频继续使用稳定 key；媒体就绪后才交接，迟到的加载及播放回调受身份和代次约束。
- 内网检测页只保留短流程中的 transform 进度动画，并已支持减少动画偏好；数据升级页使用原生进度控件。本轮没有改动连接和升级业务。

## 真实设备验收范围

本环境不能启动浏览器进程，因此没有 GPU 帧时间、实际截图或录像验收结果。自动用例验证状态、调度和几何计算，不能据此承诺所有浏览器和设备都没有掉帧。

| 场景 | 需要观察的结果 |
| --- | --- |
| 详情内容很快返回，或延迟返回 | 弹层正常从来源展开；内容增高时顶部不突然位移 |
| 快速打开、关闭、重开不同内容 | 没有旧回调清空新内容，没有空壳闪回 |
| 连续视频切换、途中关闭、马上重开 | 新旧画面连续，关闭时不归零，重开不继承上轮滑动 |
| Live Photo 播放、悬停退出、图片交接中关闭 | 退出保留当前画面，没有首帧或黑帧闪现 |
| 长图库快速滚动、加载下一批、删除卡片 | 列表没有旧锚点回拉，瀑布流没有反复重排 |
| 弹层打开时改变窗口大小或折叠屏方向 | 背景布局随视口变化，关闭目标与当前卡片位置一致 |
| 快速切设置分组、收起侧栏、移动高光 | 透明度接续，布局没有不同步的重叠 |
| 后台恢复、减少动画、低性能、原生全屏 | 旧资源及时清理，无锁死；系统和浏览器控制的切换保持可用 |

本轮为前端源码修复，未构建新的 Docker 镜像，也未部署运行中的服务。
